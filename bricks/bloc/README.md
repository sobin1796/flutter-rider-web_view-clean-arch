# Cubit Feature Brick

[![Powered by Mason](https://img.shields.io/endpoint?url=https%3A%2F%2Ftinyurl.com%2Fmason-badge)](https://github.com/felangel/mason)

Generates a feature scaffold that follows this app's existing structure:

- `data`: request/response models, remote source, and repository implementation
- `domain`: entity, repository contract, and use case
- `presentation`: Cubit, Freezed state, and screen

## Variables

- `name`: feature name. Mason converts it to snake case for folders/files and
  PascalCase for Dart types.
- `endpoint`: `AppEndpoints` static member used by the example GET request.
- `isStateless`: whether the generated screen is stateless.

The generated response and state use Freezed. After generating a feature, run
`dart run build_runner build --delete-conflicting-outputs` from the app root.
Update the sample endpoint, response fields, entity, and UI to match the API and
feature you are implementing.
